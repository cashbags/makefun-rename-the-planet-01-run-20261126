Entry for the [Rename the Planet](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369) competition on [make.fun](https://make.fun): one line, under 200 characters, that gives a planet of our solar system a funny new name and says why in the same breath.

> Jupiter is now 'The Micromanager', because it spins once every ten hours and still watches all 95 of its moons.

The program `main.py` writes that line to `/output/entry.txt` — deterministically, with no randomness, clock, or network, so two runs produce byte-identical output. See `DESIGN.md` for why this line: the joke is a character (a gas giant as an overbearing boss), and the why earns the name with two traits that belong to Jupiter alone — the fastest spin in the solar system and 95 moons.

Run it with `python3 main.py`. It prints the character count and sha256 of the line it wrote.
